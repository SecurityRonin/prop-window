# Privacy Policy

_Last updated: 2026-07-30_

prop-window is a desktop application that runs entirely on your own machine.

- **No data collection.** prop-window has no analytics, no telemetry, and no accounts. It does
  not phone home.
- **No data transmission by the app itself.** The only network requests are those made by the web
  page you point it at via `LOAD_URL` — exactly as any browser would load that page. prop-window
  adds nothing to them.
- **No storage of personal data.** The app keeps no history, profiles, or logs beyond the standard
  Chromium cache that Electron manages locally for the loaded page.

Because there is no server and no data collection, there is nothing for us to share, sell, or
disclose.

Questions: open an issue at <https://github.com/SecurityRonin/prop-window/issues>.
